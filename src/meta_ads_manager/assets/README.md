# Zasoby szablonu Bluerank

`bluerank-logo.png` to niezmieniona kopia pliku `Bluerank_logo.png` dostarczonego przez użytkownika projektu. Zachowuj proporcje 1060:305. Akcent szablonu: RGB 56, 180, 231. Logo nie stanowi pełnego brandbooka.

Fonty DejaVu Sans i DejaVu Sans Bold są dołączone dla powtarzalnej typografii i obsługi polskich znaków. Projekt fontów: https://dejavu-fonts.github.io/. Informacja licencyjna: `fonts/LICENSE-DejaVu.txt` (źródło: https://raw.githubusercontent.com/dejavu-fonts/dejavu-fonts/master/LICENSE). Zachowaj ją przy dystrybucji pakietu.
